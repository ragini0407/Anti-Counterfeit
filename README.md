# AI-Powered Blockchain-Based Fake Product Detection System

## Project Overview

An AI-powered blockchain-based system for detecting and preventing counterfeit products.

## User Roles

### Admin
- Verify manufacturers
- Approve/reject manufacturers
- Monitor products
- Monitor counterfeit activity
- View fraud alerts
- Monitor scan locations
- View blockchain records

### Manufacturer
- Register account
- Submit company details
- Wait for admin approval
- Register products
- Generate QR codes
- Monitor own products

### Consumer
- Scan QR code
- Share location
- Upload product image
- Verify product authenticity
